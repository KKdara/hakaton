# Проверка веб-интерфейса

Проверено при подготовке этой версии:

- Локальный запуск FastAPI / Uvicorn на Python 3.12.
- Автоматические интеграционные проверки веб-обёртки: точность цитат, наличие источников, область поиска, недостаток данных, предупреждение о дате, валидация запросов, отсутствие доступа к произвольным файлам, обработка ошибок, скачивание документов и передача статусов retrieval.
- Браузер Microsoft Edge: отправка вопроса, открытие источника с выделением фрагмента, поиск документа в каталоге, недостаток данных и новый диалог.
- Размеры 1440 × 1000 и 390 × 844: проверка отображения, отсутствие горизонтальной прокрутки. Ошибок JavaScript и HTTP при основном сценарии не обнаружено.
- `node --check web/static/app.js` и `docker compose config --quiet`.

Не проверено в этом окружении:

- Сборка и запуск Docker: Docker Desktop установлен, но движок не запущен. Compose-конфигурация проходит проверку.
- Реальные запросы к API эмбеддингов и реранкера: ключи и адрес сервиса не предоставлены.
- Существующий набор тестов Chroma: в локальном Python не установился транзитивный пакет `grpcio`. Новые проверки веб-обёртки выполняются отдельно и не требуют Chroma.

Интерфейс использует существующую базу, а не заранее заготовленные ответы. Результаты локального поиска обозначены как требующие проверки. Генерация юридических заключений и автоматический подбор редакции по дате в эту версию не входят.
